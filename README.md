# ImmersEYE

**An immersive virtual reality eye-tracking environment for food sensory and consumer research.**

Developed by the MATE Digital Sensory Science Research Group,
Hungarian University of Agriculture and Life Sciences.

## Overview

ImmersEYE is a Unity-based research environment developed for the
HTC VIVE Focus Vision, integrating virtual food environments,
eye tracking, areas of interest (AOIs), and interactive food selection.

## Experimental blocks

- **Block A:** Visual attention towards individual components of a plated meal.
- **Block B:** Visual attention across four complete meals.
- **Block C:** Food-related attention within a virtual dining environment.
- **Block D:** Interactive selection of four foods from 16 alternatives.

## Requirements

- Unity 6000.6.0f1
- HTC VIVE Focus Vision
- Compatible VIVE eye-tracking SDK and XR dependencies
- Android build support

## Installation

1. Clone or download this repository.
2. Open the project in Unity Hub.
3. Select Unity 6000.6.0f1.
4. Allow Unity to import the assets and packages.
5. Configure the headset and eye-tracking SDK.
6. Open `Assets/VRETScene.unity`.
7. Configure and build for the target headset.

## Important asset information

## Research outputs

The application supports gaze recording, AOI identification,
food-selection event logging and observer recording.

Participant recordings and personal data are not included.
